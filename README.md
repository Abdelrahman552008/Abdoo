# حارة آخر زمن

لعبة محاكاة اجتماعية ثنائية الأبعاد تدور في حارة مصرية خلال التسعينيات.

## التقنية
- Phaser 3
- TypeScript
- Vite

## التشغيل
```bash
npm install
npm run dev
```

## التحقق من البناء
```bash
npm run build
```

## الحالة الحالية
نواة أولية قابلة للتشغيل: مشهد حارة مرسوم برمجيًا، لاعب يتحرك بلوحة المفاتيح وأزرار اللمس، وواجهة عربية متجاوبة. هذه ليست اللعبة الكاملة بعد؛ ستضاف أنظمة العالم والشخصيات والمحاكاة تدريجيًا.
